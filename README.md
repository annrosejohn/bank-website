# 🌾 CARD Bank – Agricultural Banking Website

A responsive **agricultural banking and loan services website** inspired by the Kerala State Co-operative Agricultural and Rural Development Bank (CARD Bank).

The website focuses on agricultural loans, non-farm loans, banking services, loan products, partner banks, and agriculture-related initiatives.

## ✨ Features

* 🌱 Agricultural banking homepage
* 🔔 Important notification banner
* 🏦 Partner bank section
* 💰 Farm Sector Loans
* 🏢 Non-Farm Sector Loans
* 🎓 Education Loan
* 🚚 Vehicle Loan
* 🏠 Agriculture Land Purchase Loan
* 🌾 Farm Sector Schemes
* 💳 Kissan Samrithi Scheme
* 📊 Loan Products carousel
* 💵 Deposit Linked Loans
* 📱 Online Apply button
* 🌿 Agri Gateway section
* 🏦 Banking services navigation
* 🔐 Login modal for payment section
* ❓ FAQ section
* 📞 Help Desk and contact information
* 📱 Responsive Bootstrap layout
* 🎨 Font Awesome icons

## 🏦 Website Sections

### 🔔 Notification Bar

Displays important banking information and quick links such as:

* Our Partner Banks
* FAQs
* Schemes
* Circulars

### 🧭 Navigation Bar

The main navigation includes:

* Home
* Services
* About
* News
* Apply Now
* Get in Touch
* Make Payment

The Services menu contains options for **Deposits** and **Loans**.

### 🌾 Farm Sector Loans

The website highlights different agricultural financial services, including:

* Normal Lending
* Farm Sector Schemes
* Agriculture Land Purchase
* Homestead Farming
* Kissan Samrithi Scheme
* KSS

### 🏢 Non-Farm Sector Loans

Services include:

* Enterprise Loan
* Education Loan
* Vehicle Loan
* Second-Hand Vehicle Loan
* Swarojgar Credit Scheme
* Normal Lending

### 📊 Loan Products

A Bootstrap carousel is used to display different loan and banking-related products and information.

### 🏦 Partner Banks

A scrolling section displays different partner locations/banks across Kerala.

### 💰 Deposit Linked Loans

Provides information about short-term loans linked to customers' fixed deposits.

### 🌱 Agri Gateway

The Agri Gateway section showcases agriculture-related initiatives and resources through a visual image gallery.

### 🔐 Make Payment

A Bootstrap modal is included for the Make Payment option with a basic login form containing:

* Username
* Password
* Login button

### 📞 Footer

The footer contains:

* CARD Bank description
* Important organizations and links
* Agricultural Department
* Kerala Agricultural University
* Ministry of Agriculture & Farmers Welfare
* Help Desk
* Address
* Phone number
* Email
* Bank logo

## 📱 Responsive Design

The project uses **Bootstrap's responsive grid system and utility classes** to adapt the website to different screen sizes.

The navigation bar also uses Bootstrap's responsive collapse functionality for smaller screens.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `1000687118.png` are in the correct location.
4. Open `index.html` in a web browser.

No additional installation is required.
